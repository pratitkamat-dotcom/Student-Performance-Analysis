About the Predictor Model

Understand the dataset parameters, feature encoding, machine learning analytics, and algorithm details driving academic success predictions.

Logistic Regression Classifier

The predictions are powered by a supervised Logistic Regression model trained on historical student performance records. Logistic regression predicts probabilities of class membership (PASS vs. FAIL) using a logistic sigmoid function.

  • Feature Scaling: Grades G1, G2 and absences scaled appropriately
  • Threshold Limits: Standard 50% threshold separating pass from risk levels
  • Performance Metrics: Model optimized for high sensitivity (risk recall)

UCI Cortez Dataset

Our underlying training features are based on the popular UCI Student Performance dataset (Cortez & Silva, 2008), which records academic accomplishments in math and Portuguese courses.

The predictor maps 15 core parameters capturing family demographic profile, student study logs, weekly outings, and existing scores to deliver real-time outcomes.

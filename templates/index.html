How the Model Works

Our model utilizes student attributes classified under the UCI Cortez secondary education framework. The backend loads a pre-trained Logistic Regression classifier. Upon form submission, the inputs are mapped to binary integers and passed to the model coefficients, which predict the pass/fail label along with accuracy probability limits.

Database Storage (SQLite)

Each evaluation is stored in real-time in an SQLite relational database (`students.db`). This allows schools and teachers to maintain a history of student evaluations. You can browse all previous entries, check evaluated parameter summaries, and track logs from the Prediction History page.
